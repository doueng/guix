Test display: live tests off your screen

Workers' live tests now run in test-display, a headless sway with its own Wayland socket, seat, keyboard focus and output. Their windows, keys and screenshots never reach your Hyprland.

The problem

Workers tested headed Chrome, Ghostty and nested Hyprland on your session. The windows opened on the workspace you were using. ydotool writes to the kernel, so its keys go to whatever you have focused. A stale HYPRLAND_INSTANCE_SIGNATURE in an agent's environment could also make the old hide-the-window step fail silently.

How to use it

test-display -- CMD ARG...      # throwaway display around one command
test-display start              # shared display; prints its env
test-display exec -- CMD ...    # run in the shared display
test-display stop
desktop/bin/test-display check         # the proof below

Inside, WAYLAND_DISPLAY and SWAYSOCK name the test display and TEST_DISPLAY is set. DISPLAY and the Hyprland signature are removed, so nothing can reach your Xwayland or Hyprland. ydotool is a shim that refuses. To type, use wtype -s 150 TEXT; the short pause stops the first key being lost while the new keymap loads. swaymsg seat seat0 cursor set X Y and cursor press button1 click, and grim screenshots. Stopping the display also kills processes tagged with its name, since a sandboxed flatpak Chrome escapes the process tree.

Wired in: vimium-cljs's launch({headed: true}) refuses to run outside a test display. scripts/vomnibar-live.mjs and cookie-autoaccept's bombadil --headed re-run themselves inside one.

One exception: nested Hyprland

Aquamarine nests only in Hyprland. It wants xdg_wm_base v6, which sway 1.12 lacks, and it refused weston 16 for wl_compositor v6. Hyprland can't run headless either. So bb desktop/build/keybindings/hypr-nested.bb still nests in your Hyprland, but a window rule now puts the nested window in special:test-display silently before it maps. The run fails if your focused window changes. Tests of the real kanata input path still need ydotool on your session, and they say so.
