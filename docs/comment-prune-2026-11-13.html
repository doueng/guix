How the comment-only proof works

A lexer per language that knows strings, character literals and block comments (Scheme, Elisp, Clojure/EDN/Fennel, kanata, # configs, Rust/TS/JS, CSS, Lua, TLA+, vimscript) strips the comments from each changed file. With whitespace collapsed, the stripped text before and after matched for all 115 files.
