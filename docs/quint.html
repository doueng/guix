Quint on the guix repo

Recommendation: use both. Keep the TLA+ specs and TLC as they are. Write new state-machine specs in Quint when you want types and scripted run tests, and check them with quint verify --backend tlc, which is exhaustive and takes seconds. Treat Apalache as an extra bounded check, not the main one.

Setup

  • modules/engstrand/packages/quint.scm has two packages. quint 0.34.0 is the upstream single-file arm64 binary with its interpreter patched; its RPATH is left alone, as with Bun and Pi. apalache 0.62.4 is the upstream JVM tarball with exec java pinned to Guix's OpenJDK 25.
  • Normally Quint downloads its Rust evaluator and Apalache into ~/.quint the first time you use them. The wrapper instead sets QUINT_HOME to a store directory that holds rust-evaluator-v0.8.0 and apalache-dist-0.62.4, the exact versions this Quint looks for. Nothing downloads at run time. You can still override it by setting QUINT_HOME yourself.
  • Home installs quint through features/development.scm, and apalache comes with it, so after make home you have quint and apalache-mc. Until then, the checks run Quint through guix shell -L modules.
  • Editor: not added. quint-language-server 0.19 is an npm app with npm dependencies, pinned to quint ^0.31, and has no standalone binary. quint-mode.el and lsp-quint.el live in the quint repo, not on MELPA. Packaging them is possible but more work than one spec justifies.

What I specified

I ported the control connection of ghostty-rex to Rex, the Control part of Rexmux.tla as checked by Rexmux.connect.cfg, to desktop/build/rexmux/verify/quint/connect.qnt. The state is a single typed record. Conn, Try and Kind are sum types. Every action is written s' = { ...s, field: v }. It has the same four safety rules, NeverStranded, UpIsLive, NoLeak and the ranges of TypeOK, plus both liveness rules under the same weak and strong fairness. Three run tests script known paths: a local start, the T210 close-then-retry, and a late connect being closed.

The port is faithful. TLC on the TLA+ that Quint generates finds exactly what it finds on Rexmux.tla: 10300 states generated, 3034 distinct, depth 30.

Experience compared

  • Readability. Quint has no UNCHANGED (the TLA+ control part has 15 such lines), it has real types and enums instead of strings, and it has named helpers like take and close. It is about 125 lines against roughly 110 for TLA+, because the types and commas take space. It reads like code, and the frame bugs TLA+ invites go away.
  • quint run. Very fast, and good for a smoke test with a fixed seed, but it is random. Its traces are long, and it proves nothing.
  • quint test. This is the new thing. Scripted scenarios (init.then(a).then(b).expect(p)) pin regressions like T210 by name. TLC has no counterpart.
  • quint verify. Apalache's symbolic search grows exponentially here, because this spec is a long interleaving of small steps, which is where TLC is at its best. Use it for shortest traces at shallow depth or for specs with large data, not as the gate.
  • REPL. quint repl -r connect.qnt::connect3 lets you step through actions by hand and shows each state change as old => new. It is handy for exploring a design; TLA+ has nothing so direct.
  • Cost. Every verify or compile starts an Apalache JVM (about 3 s), and the binary is 129 MB plus a 190 MB jar. TLC through bbh.tla already gives the shortest counterexample for each rule.

Checks

  • make test (rexmux rule) runs bb verify:quint: typecheck, quint test and quint run --seed 0x1, about 4 s.
  • make verify adds bb verify:quint-mc: TLC through Quint over every state with liveness, then Apalache to 8 steps, about 2.5 min.

Recommendation

Keep TLA+, add Quint for new specs, and do not port the rest. The existing Rexmux.tla and bbh specs are compact and already checked exhaustively in seconds, so porting them gains little. For the next model, such as the super-agent cancel path or make refresh's graceful restart, Quint's types, run tests and REPL make it the better place to write it, and --backend tlc keeps TLC's guarantees. If Quint becomes the default, the follow-ups are the language server and a bbh runner for Quint, like bbh.tla.
