md-view: your own mdv

Goal: your own mdv, fitted to Guix Home, babashka, Herdr, Doom, Chrome and the phone. Outcome: I grew the existing md-view instead of adding a second viewer. One command now opens a Markdown or Org file in Chrome with live reload, in a terminal pane (-t), or in the phone's Docs (--phone). A Guix Home shepherd service keeps its server running, and Doom gets SPC m v.

What mdv is

mdv is a Rust CLI. It turns Markdown into GitHub-styled HTML and rasterizes it in headless WebKit, Edge or Chrome. It then slices the PNG into Kitty-graphics strips and scrolls them in Ghostty, Kitty or WezTerm with j k g G r o q. It reloads on save, follows the system theme, renders Mermaid, highlights code and caches pages. When stdout is not a TTY, it prints plain text.

Your setup already had half of it

desktop/bin/md-view already rendered GFM with pandoc and opened it in Chrome, and it was the default handler for text/markdown. To get around Flatpak, it wrote pages into ~/Downloads/.md-view and pre-rendered up to 200 linked files. It had no live reload, no Org support, and no terminal or phone path. Adding mdv's features to it beat shipping a second viewer.

How to use it

md-view README.md            # Chrome, live reload (also xdg-open, SPC m v)
md-view notes.org            # Org too
md-view -t README.md         # terminal pane: less, R reloads
md-view -t README.md | head  # plain text
md-view --phone README.md    # phone Docs list
md-view serve [PORT]         # what the Home service runs

The server binds 127.0.0.1 only. It serves only .md and .org files, and it refuses any request whose Host header is not its own, so a web page can't reach your files through DNS rebinding. Until the next make switch installs the md-view shepherd service, md-view FILE starts the server itself.

Live proof

All shots come from the hidden test display, a headless sway, or from headless Chrome. Nothing ran on your screen.

1. Chrome, live reload

I opened demo.md through md-view's server, then edited the file from outside. Without a click or keypress, the page reloaded with the new bold line and kept its scroll position.

2. Terminal pane, md-view -t

Ghostty, on the right, runs md-view -t demo.md. I saved a new heading, typed R with wtype, and less showed MD-VIEW DEMO, SAVED AGAIN. The prompt reads md-view (END) R reloads, q quits.

3. Phone width: a Docs export and an Org file

md-view --phone demo.md wrote /tmp/md-view-demo-cf684c36.html, and bbh.docs/listing returned it: {:title "demo.md" :description "/tmp/mdv-proof/demo.md" :temporary true}. The Org file renders its #+title, its emphasis and its source block.

Known limits

  • Phone exports don't live-reload. Run --phone again.
  • In the terminal, inline code uses pandoc's ANSI style, which is low contrast in Ghostty's theme, and images show as [image: …].
  • Herdr ships Kitty-graphics support (kitty_graphics.rs), so a raster -t mode is possible later if a native headless browser lands in the profile.
