ghostty-rex: Rex in Ghostty with a Babashka client

Outcome. MUX=ghostty-rex is now the third choice of %terminal-mux. Ghostty draws, Rex holds the sessions, and Babashka does everything else, with no Rust to compile. One Ghostty window shows one Rex session the way Herdr does: tabs, splits, title rows, status line, which-key, M-x and tiny fingers. Ghostty's own tabs and splits are not used. The parity list passes 35 of 35 live checks in a real Ghostty on the hidden test display. Herdr is still the default and rexmux is untouched.

Try it, and roll back

cd ~/guix
make mux MUX=ghostty-rex   # set %terminal-mux, home-apply, reload Hyprland
# Super+B or Super+Return opens it; Super+Return/E/D/G pick tabs 1-4
make mux MUX=herdr         # back to Herdr (or: guix home roll-back)
make mux MUX=rex           # or rexmux

Your Rex sessions survive a switch: Rex keeps them, and the rexmux and ghostty-rex windows show the same main session. Guix Home builds with the ghostty-rex choice (checked), installs rexg-render and writes ghostty-rex to ~/.config/engstrand/mux.

How it is built

  • Edit any .clj under desktop/build/ghostty-rex/src/rexg/ or the rexmux sidecar, then reopen the window. There is no build step.
  • Pane bytes never reach Ghostty, so each terminal query gets one reply, from Rex. This avoids the double-reply risk named in rex-client-languages.html.
  • Cost: Kitty graphics inside panes are not shown, since cells are composed. True colour, ligatures and the Kitty keyboard protocol work.
  • Packages: libghostty-vt 1.0.1 and rexg-render for aarch64, in modules/engstrand/packages/ghostty.scm.

What was tested

make ghostty-rex-verify runs a real Ghostty on the hidden test display (test-display, headless sway) against a throwaway Rex server with its own HOME and socket. Stubs stand in for emacs-bbh, pi, jjui, bbh, nvim and notify-send. It took about 5 minutes and passed 35 of 35 checks measured. A second run used the Guix-built rexg-render.

Not covered, and known rough edges

  • The real pointer path in Ghostty: the headless display has no pointer, so mouse checks feed SGR reports through a pty into the same handler.
  • Desktop notifications were checked through a notify-send stub, not on your desktop.
  • After a reboot, each restored pane briefly shows the exec fish -l line that brought its shell back. rexmux does the same.
  • It has not been run on your real Rex server or Hyprland session. make mux MUX=ghostty-rex is the first real use.
