How a key travels

Each layer can consume a chord before the next one sees it. A chord belongs to the first layer that binds it.

KeyboardThe physical MacBook keys.
→
kanataCaps tapped is Escape and held is Ctrl. Shift tapped types a parenthesis. Cmd chords become Linux chords, and an application layer from kanata/apps.edn can change them per window class.
→
HyprlandCtrl+Alt chords, the Alt+Space leader submap and the remaining Super (Cmd) chords. It sees window classes, not the program inside a terminal.
→
GhosttyIts own bindings and defaults, such as Ctrl+minus for the font size. Everything else goes to Herdr as terminal input.
→
HerdrThe Ctrl+b prefix, Ctrl+digits and bare Ctrl+h/j/k/l. It forwards those four to a program that keeps them under leader.edn's :terminal :keeps.
→
ProgramNeovim, Doom, fish or Pi. The editors read the Space leader in normal mode. At an editor's edge, focus moves back out through keyleader nav.

Philosophy, after Doom Emacs

Doom Emacs organises commands under one leader with mnemonic groups, shows which-key after a pause, and gives the most frequent commands single keys. This setup applies that grammar beyond Emacs. Each context enters the leader its own way, and the keys after the leader mean the same thing everywhere. The table records where each Doom principle holds and where it bends.

Inconsistencies and proposals

#FindingEvidenceProposalStatus
1SPC SPC is the command palette, not Doom's project file searchUpstream Doom binds SPC SPC to projectile-find-file and SPC : to M-x. keybindings.el binds SPC SPC to M-x, and leader.edn uses SPC for the palette in every context.Keep SPC SPC as the palette, since it is consistent across five contexts. Also bind SPC : to the palette, so Doom's documented key works in every context.open
2References are c R, Doom uses c DUpstream Doom binds c d to definition and c D to references, and c R to a references tree only when :ui treemacs +lsp is enabled. leader.edn and keybindings.el bind c R.Move references to c D in leader.edn, or add c D beside c R. Doom's uppercase-widens rule then holds, since references are the wide form of definition.open
3Single key e means different things in Herdr and Doomleader.edn gives Herdr e for edit scrollback. keybindings.el binds SPC e to Treemacs, twice, at lines 12 and 173.Delete the duplicate SPC e in keybindings.el. Decide whether e is the side panel everywhere or scrollback editing everywhere. Doom itself leaves SPC e free.open
4No shared project or workspace groupsDoom has SPC p p to switch project and SPC TAB for workspaces. 6Cmd chords in a terminal reach the shell as Ctrl keyskanata sends Ctrl+W, Ctrl+T, Ctrl+N and Ctrl+F for Cmd+W, Cmd+T, Cmd+N and Cmd+F. 7Ghostty keeps the font-size chordsGhostty consumed Ctrl+minus in a probe window, and its defaults also bind Ctrl+equal, Ctrl+plus and Ctrl+0. Emacs reads C-- as a negative argument.Keep them if terminal zoom matters, or unbind them and zoom with Cmd chords through kanata.open
8The Cmd+/ guide omits some Cmd chordshyprland.lua binds Cmd+D and Cmd+G (Herdr tabs 3 and 4), Cmd+Shift+U (workspace 3) and Cmd+comma (edit hyprland.lua). bindings.edn lists none of them.Move those binds into bindings.edn so the guide and generated keybindings.lua include them.open
9IdeaVim b b and f r run the same actionBoth map to RecentFiles in leader.edn.Use Switcher for b b, which lists open editors, and keep RecentFiles for f r.open
10Launch application sits on o a, Doom's org agenda prefixDoom's SPC o a opens org agenda commands. The binding is desktop-only, so no context runs both.Kept for the mnemonic. Doom leaves o c, o g, o h, o j, o k, o n, o q, o u, o v, o w, o x, o y and o z free if strict alignment matters more.decided
11Herdr's Ctrl+b prefix hides readline backward-charRecorded in the decision log. Ctrl+b never reaches a shell inside Herdr.Accept it and use Left or Cmd+h, or move the prefix. A prefix change touches every Herdr binding and the Cmd+Space handler.decided
12Cmd+Space typed into Ghostty windows without HerdrEvery Ghostty window shared one class.Herdr runs in the class com.mitchellh.ghostty.herdr from desktop/bin/herdr-terminal.fixed
13Pi received Ctrl+h and fzf lost Ctrl+j/kPass-through was all four keys or none per program.:terminal :keeps pairs each program with the keys it keeps.fixed
