# Vendored `herdr-tiny-fingers`

Source: <https://github.com/hotchpotch/herdr-tiny-fingers>

Revision: `2270f872d22297806a92f72ddb76b10f5983fce0`

The Rust sources, manifest, and `LICENSE` are vendored for a reproducible Nix
build. The manifest launches the packaged `herdr-tiny-fingers` binary from
`PATH`; Home Manager links this source directory into Herdr during activation.
