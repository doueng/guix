# pi-vent

Vendored copy of [`@howaboua/pi-vent`](https://www.npmjs.com/package/@howaboua/pi-vent) v0.2.1.

Upstream repository: https://github.com/IgorWarzocha/pi-vent

This shared global Pi extension adds the `vent` tool, which lets the agent append repeated or systemic workflow-friction notes to `VENT.md` in the current workspace.

The runtime entrypoint for Pi auto-discovery is `index.ts` in this directory.
